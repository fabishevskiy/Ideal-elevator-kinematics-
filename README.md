# Ideal-elevator-kinematics-
Вывод формул расчета скорости, ускорения, рывка от времени для идеальной схемы кинематики лифта, с использованием Python и библиотеки scipy. Сравнение полученных формул с формулами из статей с сайта программы по анализу трафика Peters Research. Построение графиков кинематики.
